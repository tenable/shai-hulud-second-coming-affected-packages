# Shai Hulud Package Listing

This repository contains a list of packages, in [JSON](list.json) and [table](list.md) format, that are known to be vulnerable to the Shai Hulud malware campaign. Please see the [Tenable RSO blog](https://www.tenable.com/blog/faq-about-sha1-hulud-2-0-the-second-coming-of-the-npm-supply-chain-campaign) for more information.
